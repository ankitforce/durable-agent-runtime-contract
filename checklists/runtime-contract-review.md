# Runtime contract review

- [ ] Name the workflow owner and stable task ID.
- [ ] Record the input, policy version, and data boundary.
- [ ] Identify every irreversible side effect and its idempotency key.
- [ ] Define durable checkpoints and a safe retry path.
- [ ] Define approval-required actions, reviewer role, timeout, and resume rule.
- [ ] Record tool calls, outputs, validation, exceptions, and final disposition.
- [ ] Test crash recovery and duplicate delivery before production use.
