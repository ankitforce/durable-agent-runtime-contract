# Durable Agent Runtime Contract

Companion to [**Your Agent Needs a Runtime Contract Before It Needs More Autonomy**](https://ankitkumar3514.substack.com/p/durable-agent-runtime-contract).

## Start here

1. Read [the deployment checklist](checklists/runtime-contract-review.md).
2. Copy and adapt [the YAML starter](templates/runtime-contract.example.yaml).
3. Treat the resulting file as a review artifact for one consequential workflow.

## What this contains

- A concise review checklist for state, authority, recovery, and evidence.
- A portable YAML contract starter that a team can adapt to its own runtime.

## What this does not contain

It does not provide a production runtime, credential handling, or a claim that a completed checklist makes an agent safe. It is a planning and review artifact.

## For agents

Read `AGENTS.md` before proposing changes. Preserve clear approval boundaries and never add secrets or real customer data.
